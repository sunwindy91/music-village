## 一、产品简介

### 一句话

**给山区音乐零基础的孩子，一个 AI 陪伴的「乐理寻宝」游戏**——把抽象的音高、节奏、和声、创作，变成大山世界里看得见、摸得着、玩得懂的规则。孩子玩着，就把真乐理学会了。

### 我们解决的真实问题

| 现实痛点 | 具体表现 |
|---------|---------|
| 乡村学校普遍缺专职音乐教师 | 乐理对零基础孩子是"看不见、摸不着"的抽象符号，没人教、没处学 |
| 音乐启蒙产品不接地气 | 多数 App 需账号、需联网、需付费、需高配设备，山区孩子用不上 |
| 儿童三分钟热度、怕失败 | 传统教学"答错=挫败"，孩子一错就放弃，音乐之门就此关上 |
| 教育公平的隐性缺口 | 音乐常被当成"城里孩子的特长"，而不是每个孩子都拥有的权利 |

### 核心理念

> **音乐是权利，不是天赋的恩赐。** 教育的公平，应该包括"每个孩子都值得被音乐照亮"。

**发起人寄语（邹翔）**：

> "我希望小朋友们能够挖掘自己的潜力，就像晓声一样，最后能够探索到外面世界的美好，好好地成长，以后有机会也能回报家乡。"

——这也正是晓声的故事：她从小小一粒种子出发，长出属于自己的歌声；也请孩子们相信，**你们每个人都值得被更大的世界看见**。

### 目标用户

**6–9 岁、音乐零基础、设备普通的山区儿童**。产品坚持：纯网页、零安装、零账号、零收集、离线可玩，低配手机也能跑。

## 二、产品功能

### 世界观（情感入口）

> 大山被"静默"封印了。晓声——住在晨雾山谷里的小山灵——**忘记了自己会唱歌**，请孩子陪她一起把声音找回来。孩子每点亮一座山，山谷就重新唱响一分；晓声也在陪伴中一步步长大，直到蜕变成一头会发光的小鹿。

### 山路寻宝地图（5 大聚类 · 21 关 · 全部真实乐理判题）

5 个聚类串成完整课程主线，严格按**知识依赖**排布（先听觉、再认谱与时值、后十六分与和声、最后创作），杜绝"知识的诅咒"（跳级学不会）。

| 聚类 | 课程定位 | 玩法关卡 | 乐理小测 |
|------|---------|---------|---------|
| 🌄 声音山谷 | L0 听觉启蒙 | 谁更高（音高听辨）· 小鼓手（节奏感知）· 听音找家（音高辨识） | ✅ |
| 🎵 音阶山谷 | L1 乐理主课（对齐专业吉他老师大纲） | 认识音符（唱名简谱）· 走走停停（时值）· 旋律填空（音高序列）· 看谱弹奏（视谱）· 节奏接龙（八分）· 音程梯子（音程） | ✅ |
| 🛤️ 节奏小路 | 节奏进阶 | 回声谷（节奏模仿）· 十六分赛跑（十六分音符） | ✅ |
| 🌈 和弦花园 | 和声启蒙 | 彩虹和声（听音程/和弦）· 和声找朋友（三和弦） | ✅ |
| 🌾 旋律草原 | L2 创造表达 | 旋律田（网格作曲 7×8）· 音色捉迷藏（听音色） | ✅ |

**合计：16 个玩法关卡 + 5 个乐理小测 = 21 个入口**，每个聚类都是「📖 理论导入 → 🎮 关卡练习 → ✏️ 乐理小测」教学闭环。

### 晓声 · AI 山灵（陪伴核心）

- **3D 立体手办角色**：21 张多姿态素材，答对开心、答错安抚、卡关好奇、通关庆祝，情绪姿态自动换图 + 萤火粒子
- **真实语音**：edge-tts 生成的温柔女声语音包（欢迎 / 下一站引导 / 鼓励语），晓声会"开口说话"并主动引导孩子去下一关
- **6 阶段成长进化**：种子→小芽→开花→星光→初鹿→鹿，由主线进度驱动，每次蜕变带金色粒子爆发动画——**孩子看见自己陪晓声一起长大**
- **卡关不判死**：连续错 2 次，晓声主动安抚 + 降难度重播；没有"答错"，只有"再听一次"；认识音符答错即报正确答案并重播该音（认全机制）
- **积分闭环**：答对 +10 / 通关 +50 / 作曲 +30，顶栏积分飘字 + 「我的音乐会」作品墙

### 创作出口（成品感震惊点）

- 旋律田：7×8=56 格网格作曲，每格可独立选择音色（小鸟/风铃/溪水/木琴），一键 **VexFlow 渲染真实五线谱**
- 支持 **PNG 保存 + 手写 MIDI 导出**，"我写的曲子变成真谱子"
- 作品自动存进「我的音乐会」作品墙，长期收藏孩子的第一首歌

### 隐私与可及性（默认做对）

- 无登录、无后端账号、零个人信息；进度仅存本机 `localStorage`
- 核心库与音色全部本地化，离线可玩；素材全量 webp（18MB→1.2MB）
- 触控 ≥44px、对比度达标、无纯黑纯白，写进设计宪法

## 三、产品亮点（评委视角 5 条）

### 1. 教学闭环：理论 → 练习 → 评估，一条链证明「教得会」
每个聚类 = 理论导入（晓声小课堂，先行组织者）→ 关卡练习（渐进+纠错+不判死）→ 乐理小测（形成性评估，答错报正确答案）。这是**路由级的实现**，不是口号——冒烟测试直接断言"理论导入卡先出现"。全关卡带课程编号（第 N 课 / 复习课），课程感落在 UI 上。

### 2. 真实乐理判题，不是"图形配对"
- 听辨关用 **tonal MIDI 比较**，音高判定零误差
- 节奏关用 **Tone Transport 绝对时间 + ±400ms 儿童容差窗口**，命中 ≥60% 过关，失败自动降速（bpm 88→76→72）再拍
- 难度先宽后严：两音跨度 7→5→3 半音渐进
- 孩子听到、拍到、认到的都是**真音符**

### 3. 五线谱出口 = 成品感
网格作曲一键生成**真实五线谱**（VexFlow），可存 PNG、导出 MIDI。孩子"写的歌变成真谱子"，是孩子与家长共同的成就锚点。

### 4. 晓声 6 阶成长 + 情绪姿态 + 真语音陪伴（课堂理念）
不是冰冷的"闯关打分器"，而是一个会陪着孩子长大的伙伴：3D 手办、情绪换图、TTS 开口说话、卡关降难度、通关庆祝。孩子感到"晓声在等我、在陪我"。

### 5. 儿童隐私与山区可及性默认做对 + 可冒烟验收
零收集、离线可玩、低配可跑；工程质量有 `node tools/smoke.js` **54 项断言全 PASS、零运行时错误** 自动化背书。

## 四、技术方案特色

### 1. 真实乐理引擎"三件套"（全部浏览器端运行）
| 引擎 | 职责 | 特色 |
|------|------|------|
| **tonal** | 乐理计算与判题 | MIDI 数值比较，听辨判题零误差 |
| **Tone.js** | 发声与节奏调度 | 4 种温和音色（小鸟/风铃/溪水/木琴）+ 真实节拍器 |
| **VexFlow** | 专业记谱渲染 | 孩子创作的旋律渲染成真实五线谱 |

### 2. 纯前端零构建架构
Vanilla JS + SVG，无构建链、无框架依赖、无安装，手机浏览器直接打开即玩——对山区低配设备与弱网环境极度友好。

### 3. 全量本地化 + 极致体积
Tone / tonal / VexFlow 全部本地 vendor（无业务 CDN）；素材全量转 webp，整站从 18MB 压缩到 **1.2MB**，离线可用。

### 4. 数据隐私合规
零账号、零个人信息收集，进度/积分/作品仅存本机 `localStorage`，一键可清空，符合儿童产品"最少必要"原则。

### 5. AI 分层策略（稳定与智能兼顾）
- **初赛**：规则化山灵陪伴（台词、情绪姿态、卡关降难度、成长反馈）——稳定、可离线，山区弱网不依赖云端
- **决赛预留**：大模型对话架构已预留（config 开关），可随时接入 AI 问答与个性化引导

### 6. 工程质量可验收
`node tools/smoke.js` **54 项断言全 PASS**（覆盖理论卡弹出、小测渲染、全关卡 startLevel、姿态层、语音层、五线谱 SVG、会话令牌、事件兼容层），并有全流程走查脚本。冒烟测试 + 版本号缓存策略保证每次上线"改了必验"。

### 7. 部署与分发
Cloudflare Pages 全球 CDN，国内可访问；一次部署，扫码即玩，无需应用商店审核。
