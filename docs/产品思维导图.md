## 🎯 一句话定位

**给没有音乐老师的乡村孩子，一个 AI 陪伴式音乐启蒙**——先让孩子"爱听爱唱"，再带他们"看懂乐谱"，最后能"玩出旋律"。

---

## 🧭 三层结构（教育心理学指导）

```
L0 听觉启蒙（先听先唱先动）   ← 新增（关键！补叔叔大纲的前置）
   ↓
L1 乐理进阶（叔叔专业大纲）   ← 保留（音符→时值→旋律→附点→音程→和弦）
   ↓
L2 创造表达（哼唱/音乐人格）  ← 愿景激励（初赛降级版）
```

**为什么这么分层**：儿童音乐教育共识 = 听觉先行（先听/唱/动，后读谱）+ 多感官 + 成功体验。叔叔的大纲是"乐理逻辑"，我们在前面补"听觉启蒙"，让抽象符号有身体经验打底。

---

## 📚 课程大纲（融合版）

### L0 · 听觉启蒙（新增，初赛核心）
1. **听音找朋友**：听一个音 → 找到对应的小鸟（音高辨识）
2. **节奏拍打**：跟着鼓点拍屏幕（感受时值长短：走走走·停）
3. **高低音对比**：小鸟飞高/飞低 → 点选高低（音高感知）

### L1 · 乐理进阶（叔叔大纲，初赛做前 1-2 阶）
1. 认识音符 12345671（结合 L0 的"听"来认）
2. 时值：四分/二分/全音符（用"走/停"身体化感受）
3. 简单旋律弹奏（只含三种时值）
4. 进阶：八分音符 → 十六分音符（组合）→ 附点 → 综合练习
5. 音程 → 三和弦构成/级数 → 七和弦/九和弦/挂留（**后期**）

### L2 · 创造表达（初赛降级，决赛完整）
- **初赛**：预设旋律模板 → 孩子"选择/点唱" → 显示音乐人格（小鸟型/小溪型/星星型）→ 愿景动画"学下去你也能编出这样的歌"
- **决赛**：哼唱识别 → 生成对应旋律 → 编曲

## 🤖 AI 角色（小山灵）介入层次

| 层次 | 功能 | 8/13 范围 |
|------|------|:---:|
| L1 引导反馈 | 关卡前动画引导 + 对了"太棒了"/错了"再试一次" + 积分 | ✅ 做 |
| L2 陪伴参与 | 角色全程在场、记录进步、鼓励 | ✅ 简化版 |
| L3 纠音/哼唱识别 | 听唱纠音、哼唱生成 | ❌ 初赛不做（技术难点，决赛/后期） |

**纠音说明**：浏览器单麦克风无法定位声源、嘈杂环境识别率崩——**保留到家庭安静场景或线下课堂**。

---

## 🎨 UI 与安全（公益产品硬约束）

- 深色星空 + 发光音符（复用乐理小达人视觉语言）
- 大图标、大字、低认知负担
- **无账号 + 零个人信息收集**（儿童合规 + 省服务器 + 隐私安全）
- 纯前端可跑（低配设备友好）

---

## 🧩 双 Agent 协作架构（你+队友）

```
共享仓库：
├─ docs/A2A-ROUTING.md       ← 双方 agent 必读（角色/触发词）
├─ docs/PROGRESS.md          ← 双方状态对齐（每次产出后更新）
├─ docs/A2A-DECISION-LOG.md  ← 决策流水
├─ module-audio/             ← 你：听觉/乐理/引导/积分
├─ module-voice/             ← 她：语音/旋律/视觉/动画
└─ src/index.html            ← 合并点（接口契约）
```

**关键：接口契约先行**——开工前先定接口（如 `MusicCore.playNote(id)` / `VoiceCore.listen(cb)`），双方各自实现、对齐接口，最后 merge 才能粘合。
