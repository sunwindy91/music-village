## 0. 现状摘要与坐标系约定

- **画布**：`.map-scene` 宽 `min(92vw, 560px)`，纵横比锁 **5:8**（h 版 L473-491，`padding-top:160%` hack），与 SVG `viewBox="0 0 400 640"` 等比。**换算公式：SVG 坐标 (x, y) = (x% × 4, y% × 6.4)**。节点定位用 `left:x%; top:y%` + `transform:translate(-50%,-50%)`，百分比与 SVG 坐标天然一致。

  `M200 150 C 120 190 150 260 205 300 C 260 340 250 400 196 430 C 150 456 160 520 208 548 C 236 566 232 600 214 630`
  ——一条自上（山顶/远方）而下（谷底/近处）的 S 弯虚线，是节点连线的意象基准。

## 2. 节点间路径连线（DoD ②）

### 2.1 结构：新增独立 SVG 连线层（不改动现有 `#trail`）

- 在 `svg.map-bg` 之后、节点层之前插入 `<svg class="map-links" viewBox="0 0 400 640">`，`position:absolute; inset:0; width:100%; height:100%; z-index:5`（背景之上、晓声 z6 之下——线在孩子"脚下"，晓声踩线走），`pointer-events:none`。
- **4 段独立 `<path>`**（不用一条串联 path——分段才能按通关逐段点亮），每段双层（底 6px 浅色 + 芯 4px 深色），沿用 `#trail`/`#trail-core` 的双层模式：

| 段 id | 连接 | path d（三次贝塞尔） | 弯曲方向 |
|---|---|---|---|
| `link-v-r` | valley→rhythm | `M208 102 C 150 140, 100 190, 80 243` | 左鼓（呼应弯 1） |
| `link-r-s` | rhythm→scale | `M80 243 C 140 280, 190 300, 224 333` | 微下鼓 |
| `link-s-c` | scale→chord | `M224 333 C 270 350, 310 380, 320 422` | 右鼓（呼应弯 2） |
| `link-c-m` | chord→meadow | `M320 422 C 280 460, 210 490, 184 538` | 左鼓（呼应弯 3） |

- 现有 `#trail` 保留为远景装饰，opacity 降至 0.4 作"更大的山路"底色；新连线是"能走的路"，视觉更实（dasharray 更密、色更暖）。

### 2.2 样式

- 底层：`stroke:#f3d9a4; stroke-width:6; stroke-linecap:round; stroke-dasharray:2 14; fill:none; opacity:.55`
- 芯层：`stroke:#c98a5e; stroke-width:4; stroke-dasharray:2 14; fill:none; opacity:.5`
- 虚线比 trail 的 `2 16` 略密——近景路更"实"，远景路更"虚"，层次分明。
- 曲率容差：上面 4 条 d 值为基准，导演实现时可微调控制点 ±12px 内，保证弧线不穿过节点圆（节点半径桌面 46px/移动 38px，圆心在端点，线段端点应止于圆缘——实现时用 `stroke-dashoffset` 负值或直接把端点沿切线方向缩短 50px，避免线段扎进封面图底下）。

### 2.3 通关点亮逻辑

- 节点完成态判定沿用现逻辑：该 loc 全部 levels 完成（`app.js` L184 `allDone`）。
- **连线分段点亮**：段 i（动线第 i→i+1 段）点亮条件 = 动线上**前一个节点** `allDone === true`。即 valley 全亮 → `link-v-r` 点亮；rhythm 全亮 → `link-r-s` 点亮，依此类推。全部点亮 = 一条金光路从山顶贯通谷底，呼应主题曲解锁（`app.js` L2035）。
- 点亮表现（双层 path 上叠加第三条"光层"path，同 d）：`stroke:#e8b04b; opacity:0 → 1; transition:opacity .8s var(--ease)`——**纯 opacity 动画，红线合规**。同时给该段加 `.flow` 类启动流动（§2.4）。
- 点亮时机：通关返回地图 `renderLocs()` 重渲染时执行，与节点金光同步出现（先节点亮 0.2s → 再连线淡入 0.8s，微时差更有"路被点亮"的叙事感）。

### 2.4 虚线流动动画（点亮段专属）

- 点亮段：`animation: linkFlow 1.6s linear infinite`，`@keyframes linkFlow { to { stroke-dashoffset: -16; } }`（= dash 周期 2+14，反向流动指向"下一站"）。
- **红线例外论证**：`stroke-dashoffset` 是 SVG 描边呈现属性，不触发布局/盒模型，仅 4 条细路径，实测开销与 opacity 动画同量级；且仅点亮段播放（最多 4 条）。若导演决定严守「只 transform/opacity」字面红线，备选方案：**静态虚线 + 光层 opacity 呼吸**（0.7↔1，2.4s ease-in-out），舍弃流动。
- 未点亮段：静态虚线，无动画。

## 4. 晓声拖拽交互细节（DoD ④ · 白小纯同款）

> 参考实现：来时路 v3 `enableDrag()`（L1768-1819）+ 挣扎动画 `petFight`（L301-302）。以下为移植到音乐村的完整规范，按项目约束做了 4 处适配（Pointer Events、画布内 clamp、治愈系收敛幅度、PNG 单图无动作帧）。

### 4.1 事件模型与「拖拽 vs 点击」阈值

- 使用 **Pointer Events**：`pointerdown / pointermove / pointerup / pointercancel`，`pointerdown` 中 `setPointerCapture(e.pointerId)`（白小纯用 mouse+touch 双通道 L1809-1814；音乐村已有 PointerEvent→click 全局降级层 config.js L20-26，故仅在 `window.PointerEvent` 环境启用拖拽，老浏览器晓声固定原位——优雅降级）。
- **阈值**：位移 `|dx|>4 或 |dy|>4` 判定为拖拽（白小纯 L1789 同款 4px）。
  - 未超阈值 → **点击**：触发晓声彩蛋（`MV.VoiceCore.say` 随机一句，见 §4.6），同时保留现有地图气泡行为。
  - 超阈值 → 进入拖拽：晓声**不触发** openLocation（晓声 holder 与节点 button 是不同元素，天然隔离；孩子点到晓声永远只是互动，不会误开关卡）。
- 拖拽期间 `touch-action:none`（挂在 holder 上，防浏览器滚动抢手势）；`document.body.style.userSelect='none'`（白小纯 L1782），松手还原。

### 4.2 状态机与基线建立（防首帧跳动）

```
idle ──pointerdown──▶ grabbing(未过阈) ──|Δ|>4px──▶ dragging ──pointerup──▶ dropping → idle
         │                                          │
         └──pointerup(未过阈)──▶ tap 彩蛋 → idle    └──累计位移>150px──▶ 触发一次「挣扎反抗」(§4.4)
```

- `pointerdown`：记录 `{startX, startY, baseLeft, baseTop, lastX, lastY, dist, moved:false, resisted:false}`。
- **基线固化**（白小纯 L1780-1781 的关键经验）：`getBoundingClientRect()` 后，立即把 holder 的 `bottom:12%` 百分比布局换成 `left/top` px 固定位 + `transition:none`——防止第一帧跳变。坐标统一换算到 `.map-scene` 容器坐标系（`clientX - sceneRect.left`）。
- 拖拽开始时暂停地图晓声的 float 动画（见 §4.5）。

### 4.3 拖拽范围 clamp（画布内，非窗口）

- 白小纯 clamp 到窗口（L1793-1794）；音乐村改为 **clamp 到 `.map-scene` 内**：
  `x = clamp(x, 4, sceneW − petW − 4)`，`y = clamp(y, 4, sceneH − petH − 4)`（4px 内边距防贴边）。
- 不避让节点：晓声 z6 在节点层 z8 **之下**，节点永远可点；拖拽中 holder 临时提到 z12（低于 note-float z15），松手回 z6。

### 4.4 挣扎动画与反抗彩蛋

- **拖拽全程挣扎**：holder 内层 `.xs-png-wrap` 加 `.xs-dragging`：
  `@keyframes xsDragWiggle { 0%,100%{transform:rotate(0)} 25%{transform:rotate(-6deg) translateX(-3px)} 75%{transform:rotate(5deg) translateX(3px)} }`，`.5s ease-in-out infinite`。
  - 对比白小纯 `petFight`（±9°/±4px，L302）收敛 1/3——水彩治愈系 motion_intensity 6，挣扎是"撒娇"不是"打架"。**纯 transform，合规**。
- **反抗彩蛋**：累计拖拽位移 `dist > 150px`（白小纯 L1797 阈值沿用）触发一次：快速 `translateX(∓10px→±8px→0)` 420ms（dodge 式，transform）+ 说一句反抗台词（§4.6）。一次拖拽只触发一次（`resisted` 标记），松手重置。
- **不换图**：白小纯有 fight/sword 动作图可换（L1783/1797），晓声 6 阶形态各仅一张 PNG——用 CSS 抖动 + `setExpression('surprised')` 表情切换代替，不破坏形态素材锚点（与 `docs/晓声6阶段_3D立体化Prompt.md` 的角色锚点策略一致）。

### 4.5 与 6 阶形态共存 + 松手行为

- **分层零冲突**：拖拽只改 holder（`#map-xs`）的 `left/top` 与 z-index；形态系统 `applyGrowth()` 只操作内部 `img.src`/`data-form`（voice-core.js L242-275）；形态标签 `.xs-form-tag`（app.js L151-157）是 holder 子元素，自然跟随。
- **transform 分层**：定位在 holder，挣扎在 `.xs-png-wrap`，呼吸/浮游在 `.xs-png`/`.xs`——三层互不覆盖。拖拽中给 holder 加 `.drag-hold`：`animation-play-state:paused` 停掉 float（防"拎着还自漂"的诡异感），松手移除恢复。
- **松手（两档，推荐 A）**：
  - **A · 停留原地（推荐）**：白小纯方案（L1800-1807）——孩子拖到哪就停在哪，给掌控感；位置存 `sessionStorage`（会话内记忆；不用 localStorage 跨会话——次日打开晓声应回到锚点原位，保持首页构图稳定）。回锚点入口：双击晓声 或 拖拽到距原锚点 <40px 松手时 0.35s `var(--ease)` 滑回。
  - B · 总是回弹：松手 0.35s 回锚点（更省心但削弱桌宠感，备选）。
- **节点吸附（可选 P2）**：松手点距某节点中心 < 56px（400 系）→ 0.3s ease 滑到该节点「站位点」（节点中心 + 右下 45° 偏移 (r_orb + petW/2 + 10px)），晓声说一句该 loc 的 `memory`（"晓声的梦之桥"等）——走到哪讲到哪的教学彩蛋。不吸附则按 A 停留。实现成本 ~20 行，建议二期。

## 5. 节点入场与呼吸动画规范（DoD ⑤）

### 5.1 入场（首次进入地图 / 每次 renderLocs）

- 节点：`opacity:0 + translateY(14px) scale(.8)` → `opacity:1 + translateY(0) scale(1)`，`.45s var(--ease) both`（与 `viewIn` h L91-94 同款曲线，全站一致）。
- **交错延迟按动线顺序**：valley 0ms → rhythm 120ms → scale 240ms → chord 360ms → meadow 480ms——引导孩子视线从起点走到终点（每处动效有教学理由 ✓ DESIGN.md）。
- 连线：节点全部入场后（600ms 起）光层/虚线 `opacity 0→1` 淡入 `.6s`，逐段再错 100ms。
- 晓声：沿用现有 float + breathe，不新增入场。

### 5.2 呼吸（idle 常驻）

- 节点 orb：`scale 1 → 1.03 → 1`，`3.4s ease-in-out infinite`（与 `xsBreathe` h L302 同频——晓声与节点"同呼吸"，世界感）；**每节点 delay = 序 × 0.4s 错相**，避免 5 圆同步闪烁。
- 完成态金光的 opacity 呼吸（`0.8↔1`，同 3.4s）可选；默认不开（发光常量即可，动效克制原则）。
- 呼吸作用于 orb 子元素（非定位容器），与 hover 发光、active 缩放同层互不打架。

### 5.3 prefers-reduced-motion 降级（硬规则）

| 元素 | 默认 | reduced-motion |
|---|---|---|
| 节点入场 | .45s 位移+缩放入场，交错 120ms | 直接 `opacity:1` 静态呈现（transition ≤.01s） |
| 节点呼吸 | scale 3.4s 循环 | `animation:none` |
| 连线流动 | dashoffset 1.6s（或光层呼吸） | 静态虚线，无动画 |
| 连线点亮 | opacity .8s 淡入 | 瞬时切换（≤.01s） |
| 晓声拖拽挣扎 | xsDragWiggle .5s | 无挣扎动画（**拖拽功能保留**——功能是内容不是装饰） |
| 晓声 float/breathe | 现有循环 | 现有媒体查询已覆盖（index.html L256 模式扩展即可） |

- 实现：集中一条 `@media (prefers-reduced-motion: reduce) { .loc-orb, .loc-node, .map-links path, .xs-png-wrap { animation:none !important; transition-duration:.01s !important; } }`。
