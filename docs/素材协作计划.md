> 用途：盘点 `src/assets/` 现有素材 + 按聚类课程架构列新素材清单 + 每张可直接执行的生图提示词。
> 分工：**Cursor** 出清单与提示词（本文件）→ **导演** 用 openai-next / dall-e-3 执行生图、webp 转换与提交。
> 风格锚点：延续 `src/tools/gen_assets.py` 的 **ANCHOR**——水彩 + 低饱和莫兰迪 + 大留白 + 无文字无水印 + Q版圆润。
> 日期：2026-08-12 · 分支：`cursor/f-02`

## 〇、风格锚点（所有提示词共用）

**ANCHOR 中文前缀**（与 `gen_assets.py` 完全一致，直接复用）：

```
水彩插画，晨雾山谷氛围，低饱和莫兰迪色系（雾蓝#bfe3ff/晨金#e8b04b/森林绿#3e7d5e），大留白，治愈感，高级感插画风格，无文字，无水印
```

**英文风格尾缀**（dall-e-3 中文理解有限，每条提示词末尾统一追加，稳住风格）：

```
watercolor children's book illustration, soft muted Morandi palette, chibi rounded cute shapes, gentle volumetric light, generous negative space, no text, no watermark
```

**构图通则**：
- 所有素材 `1024×1024` 生成 → 转 webp 后入 `src/assets/`（与现有素材双格式一致）。
- 封面/卡图在代码里以 `object-fit: cover` 裁成**宽横条**（聚类封面 max-height 150px、理论卡 160px）→ **主体必须集中在垂直中段横带**，上下留可裁剪空间，忌顶天立地。
- 徽章/图标类用**圆形徽章式构图 + 纯色底**（延续 person_bird/stream/star 的徽章语言）。

## 五、风险与备注

- **中文提示词风险**：dall-e-3 对中文构图描述理解有限，新提示词均为「中文主体 + 英文风格尾缀」；若生成偏离，优先加英文具体名词（如 `xylophone, wind chime, stream, bird on a music note`）重试。
- **不重复现有素材**：本清单与 15 张在线素材逐一核对无重复；6 张已生成 png 只留档提示词，不重生成。
- **风格延续**：全部沿用 ANCHOR 莫兰迪三色（雾蓝/晨金/森林绿）+ Q版圆润，与晓声 6 形态、人格徽章同一视觉体系。
- **额度估算**：待生图仅 5 张（P2×4 + P3×1），每张 1 次成功约 1 额度，含重试预留 ≤10 次。
- **假设**：① 音色关保留 4 种乐器（与 config.js 一致），故 P2 出 4 张而非信封的 3 张；② `quiz_badge` 接线位置为小测面板头部，若导演另有设计可直接复用为奖章图。
