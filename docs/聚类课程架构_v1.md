# 聚类课程架构 v1（赶工版 · 2026-08-12 深夜）

> 目标：把「单一山谷地图」升级为**多聚类课程体系**，符合 教育 → 教学 → 乐理学习 设计。
> 每个大聚类 = **理论导入（教学输入）→ 关卡演进（练习）→ 乐理小测（评估）**，形成完整教学闭环。

## 2. 教学闭环（回答"能不能教会"）

| 环节 | 实现 | 教学作用 |
|---|---|---|
| **理论导入** | 每聚类首进显示「晓声小课堂」卡片（可跳过） | 先行组织者：先概念后练习 |
| **关卡演进** | 现有关卡（听/拍/认/作），渐进+纠错+不判死 | 练习与技能形成 |
| **乐理小测** | 每聚类 3 题选择题（乐理小达人式），答对 +10 | **形成性评估**：验证是否真学会 |

> 这正是之前缺的「形成性评估」闭环：测过才知道教会没有，评委看得见"教学-练习-评估"完整链路。

## 3. 内容清单（先做框架 + 声音山谷完整，再横向复制）

### 理论导入文案（晓声口吻）
- **声音山谷**：声音有高有低——高的像小鸟飞上天，低的像溪水流下坡；还有长有短——短的叫「走」，长的叫「走——」。耳朵就是最好的老师。
- **音阶山谷**：音乐家把七个声音排成楼梯，就是音阶 do re mi fa sol la si。音符还会走路：走一步是四分，走两步是二分，走四步是全音符。
- **旋律草原**：把喜欢的音符排排队就变成旋律——你的歌！写下来就是五线谱，谁都看得懂。歌有性格：跳来跳去是小鸟，缓缓流动是小溪，往高处飞是星星。

### 乐理小测题（每题：题干 + 3 选项 + 答案）
- **声音山谷**：① 高的音像什么（小鸟飞得高）② 「停」的时候要（休息不动）③ 声音高低叫（音高）
- **音阶山谷**：① do re mi 之后是（fa）② 「走——」比「走」长（一倍）③ 1-7 最后一个数字是（7）
- **旋律草原**：① 五线谱越往上音越（高）② 歌存成图片为了（带回家给爸妈看）③ 蹦蹦跳跳的歌是（小鸟型）
