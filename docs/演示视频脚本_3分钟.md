# 🎬 3 分钟演示视频脚本 · 大山里的音乐课

> 用途：8/13 初赛提交 · 可玩原型演示
> 录制：手机/录屏 + 旁白（普通话，亲切、儿童向）
> 时长：约 3 分钟 | 关联材料：方向材料 + 可玩链接
> 演示入口：https://music-village-app.pages.dev

## 🎬 分镜脚本

### 【0:00-0:20】开场 · 一句话定位
**画面**：产品首页（大山地图全景）渐显
**旁白**：
> 山区很多学校没有音乐老师。这里的孩子，其实对声音有着天然的感知——鸟叫、溪流、风声。缺的，只是有人把"声音的秘密"讲给他们听。
> 我们做的，就是一款 AI 陪伴的**乐理寻宝游戏**——让抽象的音高、节奏、和弦，变成大山世界里看得见、摸得着、玩得懂的规则。

### 【0:20-0:50】山路地图 · 寻宝世界观
**画面**：地图上滑动，经过声音山谷→音阶山谷→节奏小路→和弦花园→旋律草原（山路虚线，从山脚到山顶）
**旁白**：
> 从山脚的小屋出发，一条山路通向山顶。每到一个地方，就点亮一个乐理知识点。今天，我们跟着山灵去"音阶山谷"——帮音符鸟重新唱出歌来。

### 【0:50-1:25】关卡一 · 看小鸟飞（观察，零压力）
**画面**：进入"看小鸟飞"，点击播放，小鸟沿五线谱从左往右飞，落点越高音越高，彩色轨迹像一幅画
**旁白**：
> 第一关，不用做题，只用看和听。音符鸟从五线谱天空飞过——它落到越高的地方，唱出来的音就越高。孩子天然就能看见：**高 = 上面，低 = 下面**。这就是"音高"最底层的视觉启蒙。

### 【1:25-2:00】关卡二 · 点小鸟回家（配对，即时反馈）
**画面**：进入"点小鸟回家"，山灵唱一个音，孩子点对应小鸟；答对发光+加分+连击，答错"再听一次"+提示高低
**旁白**：
> 第二关，山灵唱一个音，孩子点出"唱得一样高"的小鸟。答对了，小鸟回家、积分飞起；答错了，永远不会打"×"——山灵会说"再往上一点，它站得更高哦"。孩子是在**玩**里学会听音高的，而且越玩越想玩。

### 【2:00-2:30】关卡三 · 排排队（排序，音阶心智）
**画面**：进入"排排队"，从最低的小鸟开始一只只往上点，小鸟按 1-2-3-4-5 入队，最后音阶从低到高完整响起
**旁白**：
> 第三关，"排排队"——按从低到高，让小鸟们站好队。孩子们不背 do-re-mi，而是在动手排序中，自己"长"出了**音阶**的概念。排队成功，音阶响起的那一刻，就是这座山谷被点亮的时候。

### 【2:30-3:00】总结 · 机制与未来
**画面**：回到地图，展示"每个知识点=一张地图"的世界观 + 山灵对话
**旁白**：
> 我们的核心，是把乐理变成**世界的规则**，配合 AI 山灵全程陪伴：鼓励、提示、庆祝，从不让孩子卡死。接下来，声音山谷、节奏小路、和弦花园会陆续点亮——最终让孩子从"爱听爱唱"，走到"看懂乐谱"，再到"玩出自己的旋律"。
> 让每一个大山里的孩子，都能开口歌唱。谢谢！

## 📋 录制提示

1. 用**手机横屏**或电脑录屏（Chrome 打开 https://music-village-app.pages.dev）
2. 旁白要**亲切、慢一点**，想象在对小朋友说话
3. 关键镜头（小鸟飞高、排队成功）可以**短暂停留**让观众看清
4. 背景音乐可选：轻快木琴/尤克里里（不要盖过旁白）
5. 全程 3 分钟内，宁可剪短不要超时
