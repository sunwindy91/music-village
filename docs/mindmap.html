给没有音乐老师的乡村孩子 · 一个 AI 陪伴式音乐启蒙
🏆 小有可为 AI 向善挑战赛 📅 初赛 8/13 🎓 教育心理学指导 🤖 A2A 双 Agent 协作
🎯定位一句话
先 爱听爱唱 → 再 看懂乐谱 → 最后 玩出旋律
核心：不是教乐理，是让孩子愿意打开、愿意坚持、感受到音乐的美好
🌱L0 听觉启蒙初赛核心 · 必做
① 听音找朋友 听一个音 → 找到对应小鸟音高辨识 · 即时反馈
② 节奏拍打 跟着鼓点拍屏幕感受时值长短：走走·停
③ 高低音对比 小鸟飞高/飞低 → 点选音高感知训练
🎓 听觉先行原则：先听/唱/动，后读谱
📚L1 乐理进阶叔叔专业大纲
初赛范围 音符 12345671 · 时值（四分/二分/全音符）· 简单旋律
中期 八分 → 十六分（组合）→ 附点音符 → 综合练习
后期 音程 → 三和弦/级数 → 七和弦/九和弦/挂留
🧑🏫 来源：邹翔叔叔（专业吉他老师·乐理通）
🎨L2 创造表达愿景激励
初赛 · 音乐人格 选/点唱旋律 → 显示小鸟/小溪/星星型愿景：学下去你也能编出这样的歌
决赛 · 哼唱生成 哼唱识别 → 生成对应旋律 → 编曲体验
🤖AI 小山灵三层介入
L1 引导反馈 对了"太棒了 🎉" · 错了"再试一次 💪" · 积分系统
L2 陪伴参与 全程在场 · 记录进步 · 鼓励坚持
L3 纠音识别 技术难点：浏览器单麦克风无法定位声源、嘈杂环境识别崩 → 保留家庭/线下场景
🛡️UI 与安全公益硬约束
深色星空 + 发光音符（复用乐理小达人视觉语言）
大图标 · 大字 · 低认知负担
无账号 + 零个人信息收集儿童合规 · 隐私安全 · 纯前端低配可跑
