## 一、30 秒电梯稿

给山区 6–9 岁零基础儿童的 **AI 陪伴式乐理寻宝游戏**。用真实乐理引擎（tonal 判题 + Tone.js 发声 + VexFlow 五线谱）把音高、节奏、创作变成山谷里的寻宝；晓声山灵全程陪伴，卡关不判死；纯前端、无账号、零收集、离线可玩。

## 二、项目亮点（5 条）

### 1. 真实乐理判题，不是「图形配对」
- 听辨关用 **tonal MIDI 比较**，音高判定零误差（见验收包 P0「音之梯」）。
- 小鼓手用 Tone Transport 绝对时间 + ≤250ms 窗口判拍，命中率 ≥60% 过关（`config.js`：`drumWindowMs` / `drumHitRate`）。
- 孩子听到的是真音符，不是换皮点选。

### 2. 五线谱出口 = 成品感震惊点
- 网格作曲（Chrome Music Lab Song Maker 式，5×8）一键 **VexFlow 渲染真实五线谱**。
- 支持 PNG 保存 + 手写 MIDI Format 0 导出（`modules/notation/staff.js`）。
- 「我写的曲子变成真谱子」——孩子与家长都有成就锚点。

### 3. 晓声 6 阶成长 + 卡关陪伴课堂理念
- 成长：种子→小芽→开花→星光→初鹿→鹿（点亮关卡数驱动，`voice-core.js` FORMS）。
- 连续错 2 次触发 stumble 降难度台词（`lines.js`）；无「答错」话术，只有「再听一次」。
- 通关主题曲框架已预留（`config.js` `themeSong`）。

### 4. 儿童隐私与山区可及性默认做对
- **无账号、零个人信息**；进度仅 `localStorage`（键名 `mv-progress-v2`）。
- Tone / tonal / VexFlow **全部本地 vendor**，无业务 CDN（Google Fonts 非阻塞，失败可回退系统字体）。
- 触控 ≥44px、对比度与无纯黑纯白写进设计宪法（`docs/DESIGN.md`）。

### 5. 三大教学法可验证落点 + 可冒烟验收
- 柯达伊（先听先唱）/ 奥尔夫（拍）/ 达尔克罗兹（听辨反应）→ 对应关卡动作（见 `0到1完整设计方案.md`）。
- 课程结构 L0→L1→L2 已落地：声音山谷 3 关 + 认识音符 + 旋律田。
- `node tools/smoke.js` **27 项断言全 PASS**（含真实 VexFlow SVG、会话令牌、事件兼容层）。

## 三、常见 Q&A（10 个）

### Q1. 这和普通「儿童音乐 App」有什么不一样？
**A：** 多数启蒙 App 是跟唱/动画听赏；我们把 **真实乐理内核**（判题引擎 + 合成器 + 记谱）做成寻宝世界，并且创作能导出 **真五线谱/MIDI**，不是贴图奖励。

### Q2. 「AI 陪伴」具体指什么？初赛有没有接大模型？
**A：** 初赛是 **规则化山灵陪伴**（打字机台词、表情、卡关降难度、成长反馈），稳定可离线。大模型对话在架构上预留（开发手册写明 `askSpirit` / config 开关思路），决赛再开——山区弱网不能依赖云端才能玩。

### Q3. 如何证明「真的在教乐理」而不是玩具？
**A：** 关卡对齐叔叔专业大纲（认识音符 1–7 等）；判题用 MIDI/拍点，可复现；学习闭环含「答错报正确答案并再播该音」（认识音符）。冒烟测试覆盖五关 `startLevel` 与变谱流程。

### Q4. 数据隐私怎么做的？会不会上传孩子信息？
**A：** **不收集**。无登录、无后端账号；积分/通关/作品只写本机 `localStorage`。重置按钮可一键清空。符合儿童向产品「最少必要」原则。

### Q5. 山区没网 / 低配设备能不能用？
**A：** 核心脚本与音色库本地化；纯前端零构建，手机浏览器即可。弱网时字体可能回退，但不阻塞进游戏。建议用系统浏览器打开以保证音频上下文可解锁。

### Q6. 技术栈为什么选 Tone.js / tonal / VexFlow？
**A：** 分别解决「发声与节奏调度」「乐理计算判题」「专业记谱渲染」——与 `0到1完整设计方案.md` 三层内核一致，且均可浏览器端运行，适合 Pages 一键部署。

### Q7. 防挫败机制有哪些？
**A：** ① 话术无「答错」② 连续卡关 stumble 陪伴 ③ 小鼓手 60% 命中即可过 ④ 听辨跨度先宽后严（7→5→3 半音）⑤ 三错进示范（产品铁律，见开发手册；具体关卡按实现迭代）。

### Q8. 「音乐人格」是不是伪科学标签？
**A：** 人格卡是 **创作激励**，不是测评诊断：按旋律特征（跳进/级进/音域走向）给小鸟型/小溪型/星星型 + 愿景文案「学下去，你也能编出这样的歌」，服务动机而非贴污名标签。

### Q9. 可扩展性如何？队友怎么加关卡？
**A：** 内容层在 `shared/levels.js` 填模板；`app.js` 按 `type` 分派 runner。开发手册写了「三件套」：乐理概念 / 心智模型 / 游戏动作。接口契约见 `docs/接口契约-INTERFACE-CONTRACT.md`。

### Q10. 初赛演示最想让评委记住哪 10 秒？
**A：** **旋律田点「变成五线谱」的瞬间**——孩子刚种的种子变成真谱；再加一句：全程无账号、晓声陪着「再试一次」。这 10 秒同时打中教育效果、技术含量与人文温度。
