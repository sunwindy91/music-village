## 一、30 秒电梯稿

给山区 6–9 岁零基础儿童的 **AI 陪伴式乐理寻宝游戏**。我们把课程做成了「会教」的完整闭环：3 大聚类（声音山谷/音阶山谷/旋律草原），每个聚类都是 **理论导入（晓声小课堂）→ 关卡练习（真实乐理判题）→ 乐理小测（形成性评估）** 三步走——先讲概念，再玩着练，最后测一测证明真学会。8 个关卡全部用真实乐理引擎（tonal 判题 + Tone.js 发声 + VexFlow 五线谱）；晓声山灵全程陪伴，卡关不判死；纯前端、无账号、零收集、离线可玩。

## 二、项目亮点（5 条 · v4 升级版）

### 1. 教学闭环：理论 → 练习 → 评估，一条链证明「教得会」★v4 新
- 每个聚类 = **📖 理论导入**（「晓声小课堂」卡片，首进显示、可跳过，先行组织者）→ **🎮 关卡演进**（渐进+纠错+不判死）→ **✏️ 乐理小测**（3 题选择题，**形成性评估**）。
- 这不是口号，是路由级的实现：进聚类先弹理论卡（`MV.theories`），关卡列表末尾挂小测入口（`type: 'quiz'` 关卡），冒烟测试断言「理论导入卡先出现（教学闭环第一步）」。
- 评委视角：看得见「教—学—评」完整链路，而不是一个孤立的玩具关卡。

### 2. 真实乐理判题，不是「图形配对」
- 听辨关用 **tonal MIDI 比较**，音高判定零误差（见验收包 P0「音之梯」）。
- 小鼓手用 Tone Transport 绝对时间 + **±400ms 儿童容差窗口**判拍，命中率 **≥60%** 过关；失败自动降速 **bpm 88→76→72** 再拍（`config.js`：`drumWindowMs`/`drumHitRate`；`app.js` 降速逻辑）。
- 难度先宽后严：谁更高两音跨度 **7→5→3 半音** 渐进（`highlowSpans`）。
- 孩子听到、拍到、认到的都是真音符，不是换皮点选。

### 3. 五线谱出口 = 成品感震惊点
- 网格作曲（Chrome Music Lab Song Maker 式，**5×8=40 格**）一键 **VexFlow 渲染真实五线谱**。
- 支持 PNG 保存 + 手写 MIDI Format 0 导出（`modules/notation/staff.js`）。
- 「我写的曲子变成真谱子」——孩子与家长都有成就锚点；作品进「我的音乐会」墙。

### 4. 晓声 6 阶成长 + 卡关陪伴课堂理念
- 成长：种子→小芽→开花→星光→初鹿→鹿（点亮关卡数驱动，`voice-core.js` FORMS），形态切换带金色粒子蜕变动画。
- 连续错 2 次触发 stumble 降难度台词（`lines.js`）；无「答错」话术，只有「再听一次」；认识音符答错**报出正确答案并重播该音**（认全机制）。
- 通关主题曲框架已预留（`config.js` `themeSong`，全部点亮后自动奏响）。

### 5. 儿童隐私与山区可及性默认做对 + 可冒烟验收
- **无账号、零个人信息**；进度仅 `localStorage`（键名 `mv-progress-v2`，理论已读独立键 `mv-theory-seen`）。
- Tone / tonal / VexFlow **全部本地 vendor**，无业务 CDN（Google Fonts 非阻塞，失败可回退系统字体）；素材全量 webp（18MB→1.2MB）。
- 触控 ≥44px、对比度与无纯黑纯白写进设计宪法（`docs/DESIGN.md`）。
- `node tools/smoke.js` **38 项断言全 PASS、无运行时错误**（v3 时期 27 项 → 新增理论卡/乐理小测/走走停停/旋律填空/音色捉迷藏断言后 38 项，2026-08-13 本机实测复核）。

## 三、常见 Q&A（13 个 · v4 扩充）

### Q1. 这和普通「儿童音乐 App」有什么不一样？
**A：** 多数启蒙 App 是跟唱/动画听赏；我们把 **真实乐理内核**（判题引擎 + 合成器 + 记谱）做成寻宝世界，并且组织成**课程**：理论导入→关卡→小测。创作能导出 **真五线谱/MIDI**，不是贴图奖励。

### Q2. 「聚类」是什么？为什么这样组织课程？★v4 新
**A：** 聚类 = 一个**完整的最小教学单元**。我们把原来的单线地图升级为 3 个并列大聚类：**声音山谷（L0 听觉启蒙）→ 音阶山谷（L1 乐理进阶，对齐叔叔专业大纲）→ 旋律草原（L2 创造表达）**。每个聚类内部都是「理论导入（晓声小课堂）→ 关卡练习 → 乐理小测」三段闭环——这是从「游戏关卡集合」到「课程体系」的关键一跃（架构详见 `docs/聚类课程架构_v1.md`）。

### Q3. 如何证明「真的教会了」，而不是玩得开心而已？★v4 重点
**A：** 三处可验证：
1. **形成性评估已上线**：每聚类末尾的乐理小测（3 题选择题，覆盖本聚类核心概念——如「声音的高低叫音高」「do re mi 之后是 fa」「五线谱越往上音越高」），答错当场报正确答案，全对才点亮。测过，才知道教会没有。
2. **判题可复现**：听辨用 MIDI 比较零误差、节奏用 ±400ms 窗口 + 60% 命中线，都是确定性规则而非感觉。
3. **工程可验收**：`node tools/smoke.js` **38 项断言全 PASS**，其中直接覆盖理论卡弹出、小测渲染与选项、各关卡 startLevel——流程完整性有自动化背书。

### Q4. 「AI 陪伴」具体指什么？初赛有没有接大模型？
**A：** 初赛是 **规则化山灵陪伴**（打字机台词、表情、卡关降难度、成长反馈），稳定可离线。大模型对话在架构上预留（开发手册写明 `askSpirit` / config 开关思路），决赛再开——山区弱网不能依赖云端才能玩。

### Q5. 新增的 3 个关卡分别教什么？★v4 新
**A：**（均在 `src/shared/levels.js` 可查，冒烟已覆盖）
- **走走停停**（音阶山谷）：时值听辨——听声音长短，判断音符「走了几步」：走（1 拍）/ 走——（2 拍）/ 走————（4 拍），把四分/二分/全音符变成「脚步声」。
- **旋律填空**（音阶山谷）：听一段旋律，补上缺的那个音——从单音听辨升级到**音高序列**感知。
- **音色捉迷藏**（旋律草原）：听音色辨乐器——小鸟（轻快啾啾）/ 风铃（叮咚亮晶晶）/ 溪水（咕噜咕噜流）/ 木琴（圆润咚咚）4 种音色各考一轮。

### Q6. 数据隐私怎么做的？会不会上传孩子信息？
**A：** **不收集**。无登录、无后端账号；积分/通关/作品只写本机 `localStorage`。重置按钮可一键清空。符合儿童向产品「最少必要」原则。

### Q7. 山区没网 / 低配设备能不能用？
**A：** 核心脚本与音色库本地化；纯前端零构建，手机浏览器即可。弱网时字体可能回退，但不阻塞进游戏。建议用系统浏览器打开以保证音频上下文可解锁。

### Q8. 技术栈为什么选 Tone.js / tonal / VexFlow？
**A：** 分别解决「发声与节奏调度」「乐理计算判题」「专业记谱渲染」——与 `0到1完整设计方案.md` 三层内核一致，且均可浏览器端运行，适合 Pages 一键部署。

### Q9. 防挫败机制有哪些？
**A：** ① 话术无「答错」② 连续卡关 stumble 陪伴 ③ 小鼓手 60% 命中即可过、失败自动降速 88→76→72 ④ 听辨跨度先宽后严（7→5→3 半音）⑤ 三错进示范（产品铁律，见开发手册；具体关卡按实现迭代）⑥ 理论卡可跳过、小测答错报答案不扣分惩罚。

### Q10. 「音乐人格」是不是伪科学标签？
**A：** 人格卡是 **创作激励**，不是测评诊断：按旋律特征（跳进/级进/音域走向）给小鸟型/小溪型/星星型 + 愿景文案「学下去，你也能编出这样的歌」，服务动机而非贴污名标签。

### Q11. 可扩展性如何？队友怎么加关卡？
**A：** 内容层在 `shared/levels.js` 填模板（含 `MV.theories` 理论卡、`MV.quizzes` 小测题）；`app.js` 按 `type` 分派 runner。开发手册写了「三件套」：乐理概念 / 心智模型 / 游戏动作。聚类架构下，新聚类 = 1 段理论 + N 个关卡 + 1 组小测题，横向复制即可。

### Q12. 到底几关？数字怎么口径不一？★v4 新（评审敏感点预案）
**A：** 统一口径：**8 个玩法关卡 + 3 个乐理小测 = 11 个入口**，分属 3 个聚类：
- 声音山谷 4 入口：谁更高 / 小鼓手 / 听音找家 / 乐理小测
- 音阶山谷 4 入口：认识音符 / 走走停停 / 旋律填空 / 乐理小测
- 旋律草原 3 入口：旋律田 / 音色捉迷藏 / 乐理小测

历史材料中「5 关」指 8/12 前的 P0+P1 五关（谁更高/小鼓手/听音找家/认识音符/旋律田）；8/12 深夜新增 3 关后 = **5+3=8 关**。乐理小测是评估环节，与玩法关分开计数；若合并入口算则 11。任何场合请先报「8 关 + 3 小测」，再按追问展开。

### Q13. 初赛演示最想让评委记住哪 10 秒？
**A：** **旋律田点「变成五线谱」的瞬间**——孩子刚种的种子变成真谱；再加一句：每个聚类学完还有小测验收，全程无账号、晓声陪着「再试一次」。这 10 秒同时打中教育闭环、技术含量与人文温度。
