## 二、晓声 · 完整设定（灵魂核心）

### 是谁
> 一只**失去声音记忆的空灵小鹿（晓声）**。因为"静默"封印，她忘了自己会唱歌，也忘了自己是谁。孩子遇到她时，她安静、透明、几乎融入山色——像刚睡醒的山里孩子。

### 成长弧线（= 游戏进度可视化！）
每点亮一张地图，晓声找回一段记忆，**她的身体随之变化**：

| 地图 | 找回的记忆 | 晓声的变化 |
|------|-----------|-----------|
| 🏞️ 声音山谷 | 她最初的听觉 | 轮廓清晰，身上浮现**第一抹暖色** |
| ⛰️ 音阶山谷 | 她的歌喉 | 能开口哼唱，声音有了高低 |
| 🛤️ 节奏小路 | 她的脚步 | 会跳舞，身上泛起**第二层色彩** |
| 🌸 和弦花园 | 她的花园 | 身体开出**花的纹理**，色彩更丰富 |
| 🌾 旋律草原 | 她的梦 | 全身被**流光包裹**，长出一双光之翅膀 |

### 终点仪式（Spiritfarer 式的"告别"）
> 五张地图全亮，晓声完全苏醒。她第一次完整唱出一首歌——然后，她轻轻飞起来，回头对小朋友说："谢谢你帮我找回声音。外面的世界很大，你也要勇敢地唱呀。" 然后飞向远方的光。
> **但晓声没有消失**：她留下了一颗种子/一颗星，孩子带着它继续去新地图（后续内容入口）。

> **情感核心**：孩子不是"学会乐理"，而是"陪一个山里的小孩找回自己，然后目送她自由"。这是被治愈的瞬间。

## 四、画面质感提升路径（你要的"逼近队长渲染程度"）

### 方案 A：AI 生图（最快出"水彩空灵感"）
1. 用 **即梦 / 可灵 / Midjourney** 生成：
   - 晓声形象：空灵小鹿（水彩 + 光粒子）
   - 5 张地图背景：晨雾山谷 / 星空歌台 / 萤火小路 / 花园 / 流光大草原
2. 导出 PNG → 放 `src/assets/` → 作为背景图层
3. 前端保持轻量：图片 + 少量粒子动画（Canvas 2D，低配友好）

### 方案 B：程序化粒子（队长的路线，但用 Canvas 2D 而非 Three.js）
- 晓声身边：萤火光点环绕（已有 sparkle，可升级为粒子系统）
- 通关时：光点汇聚成翅膀的粒子动画
- 地图：溪水流动、云飘、星光闪烁（SVG/CSS 动画）

### 我的建议：**A 出关键美术（晓声 + 背景），B 做动态氛围**——两者结合，逼近 Bloom 的质感但保持纯前端低配。

> 具体操作：你想做时告诉我，我给你写一份**生图 prompt 清单**（每个场景的英文/中文提示词），你直接在即梦/可灵粘贴生成即可。
