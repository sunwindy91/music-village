给山区零基础孩子的 AI 陪伴式「乐理寻宝」启蒙 · 乐理 = 世界的物理规则
🎵 大山里的音乐课音乐寻宝游戏

🎯 一句话定位

不是教乐理的工具
是让孩子愿意打开、愿意坚持、感到美好的游戏
核心机制
越高=音越高路长=音长三色=和弦
目标
让抽象乐理 看得见、摸得着、玩得懂

👧 用户与场景

主用户：6-9 岁山区零基础儿童
场景：乡村课后 / 家庭手机平板 / 无音乐老师
设备：纯网页 · 零安装 · 低配可跑
儿童心理：怕失败 → 无"答错"只有"再试"

🔄 核心体验循环

①观察 看小鸟飞 · 建立心智映射
②体验 自由玩 · 试错无惩罚
③挑战 小目标 · 驱动练习
④成就 点亮石碑 · 勋章解锁

🖥️ 画面流程

启动 → 太阳升起 + 山灵问候
大山地图 → 山路串起 5 个地点
关卡总览 → 山灵介绍 + 关卡 chips
关卡舞台 → 五线谱 + 操作 + 反馈
成就反馈 → 勋章 + 积分 + 庆祝

🎮 关卡机制（三件套）

三件套：概念 × 心智模型 × 游戏动作
observe看小鸟飞 ✓
point点小鸟回家 ✓
sort排排队 · 音阶 P1
sing回声山谷 · 音准 P1
boss点亮石碑 · 成就 P1

✋ 交互规范（8条）

大目标区 ≥44px · 热区大于视觉
悬停只发光 不位移（防抖修复）
无"×"语言 · 逼近引导（高/低一点）
过程有奖励 · 进度永远可见
一次一件事 · 术语藏开发者模式
音效温柔 · 容错先宽后严
