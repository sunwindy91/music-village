## 一、项目一句话

**给没有音乐老师的乡村孩子，一个 AI 陪伴式乐理启蒙老师**——用游戏化的方式，让零基础孩子也能"玩着学会"基础乐理。

---

## 二、解决的真实问题

### 背景痛点（真实数据）
- 乡村小学普遍**缺音乐专职教师**（很多学校音乐课由语文/数学老师代上）
- 现有音乐 App 需要家长陪练/有设备门槛，乡村家庭难支持
- 音乐启蒙缺失 → 影响孩子对艺术的感知与表达自信

### 我们解决
| 痛点 | 我们的方案 |
|------|-----------|
| 没有音乐老师 | AI 老师 7×24 陪伴，语音+视觉互动 |
| 设备门槛高 | 手机/平板即可，纯网页运行（零安装） |
| 枯燥不想学 | 游戏化：音符→收集→奏乐，即时反馈（已验证） |
| 学习无反馈 | 每步即时判定 + 鼓励（孩子的成就感） |

---

## 三、核心产品设计

### 3.1 学习主线（3 个"大山关卡"）
1. **听音入门**：听→认（像"找朋友"，听到 C 音找到对应小鸟）
2. **节奏闯关**：跟着鼓点拍打（节奏感训练）
3. **和弦色彩**：三音组合→变"彩虹"（像乐理小达人已验证的和弦色彩）

### 3.2 AI 陪伴角色
- 一个"小山灵"角色：陪孩子学、鼓励、记录进步（不枯燥）
- 语音对话：孩子说"我学会了"，AI 出题考他

### 3.3 趣味 UI
- 深色星空 + 发光音符（复用乐理小达人已验证的视觉语言）
- 大图标、大字、低认知负担（适合乡村儿童 + 低配置设备）

### 3.4 技术安全兜底（公益产品必须）
- 无账号体系（本地存储），**零个人信息收集**（儿童隐私合规）
- 无外链广告，纯学习内容
- AI 输出经过内容过滤（面向儿童的安全词库）

## 五、技术方案

- 前端：Vanilla JS / Web Audio API / Canvas 2D（零构建链，低配设备友好）
- AI：阿里通义大模型（赛事补贴）+ DeepSeek（备用）
- 数据：localStorage 本地存储（零服务器，隐私安全）
- 部署：静态托管（免服务器成本）
