## 一、视图树（画面流）

```
启动 Splash（太阳升起·晓声打招呼·3s 自动/点击跳过）
  └─ 大山地图 TrailMap（山路寻宝·5 地点·晓声常驻·成长可视化）
       ├─ 地图点击 → 记忆叙事 Memory（晓声的回忆·逐条推进）
       │    └─ 关卡总览 LevelOverview（关卡 chips·晓声介绍）
       │         ├─ 关卡舞台 Stage（按类型分派）
       │         │    ├─ observe 看小鸟飞
       │         │    ├─ highlow 谁更高
       │         │    ├─ point   点小鸟回家 / 听音找朋友
       │         │    ├─ sort    排排队
       │         │    ├─ tap     小鼓手 / 走走停停
       │         │    ├─ collect 三色花（和弦花园）
       │         │    └─ draw    画旋律（旋律草原）
       │         └─ 成就反馈 Celebration（勋章+积分飞入+晓声庆祝+解锁提示）
       └─ 五图全亮 → 终章仪式 Ending（晓声苏醒·飞翔·预留）
```

## 二、核心组件清单

| 组件 | 说明 | 精工要求 |
|------|------|---------|
| 晓声（SVG 空灵小鹿） | 陪伴 IP，5 阶成长（轮廓→暖色→色彩→花纹→光翼） | 水彩质感、呼吸动画、萤火粒子、表情（安静/开心/思考/鼓励/惊讶） |
| 打字机对话气泡 | 晓声说孩子话 | 逐字显示、可跳过、语音朗读可选 |
| 天空氛围层 | 晨雾渐变 + 太阳 + 云飘 + 山峦剪影 + 溪水/星光 | 克制动效，transform/opacity |
| 顶栏 | 返回 + 地图名 + 积分/勋章 | 大目标 ≥44px |
| 关卡导航 chips | 完成打勾 + 当前高亮 | pill 全圆角 |
| 五线谱舞台 | 木色线 + 发光音符 + 小鸟 | 观察/配对/排序共用 |
| 大鼓 / 三色花 / 旋律画布 | 节奏/和弦/旋律舞台 | 各类型独立舞台 |
| 开发者模式 ⚙️ | 乐理三件套（概念/模型/动作/判定/目标） | 默认隐藏，家长/老师看 |

## 三、技术结构（从零，纯前端零构建）

```

```

## 四、设计宪法落实清单（对照 docs/DESIGN.md）

- [x] 无纯黑纯白；卡片奶油白 #fff8ec；正文墨绿灰 #37423b
- [x] 饱和度 ≤70%；晨光金 #e8b04b（非纯黄）
- [x] 圆角：大容器 24 · 卡片 16-20 · 交互 pill
- [x] 触控目标 ≥44px；发光 = 可点
- [x] hover 只发光不位移；SVG 禁 transform 缩放
- [x] 动效全 transform/opacity；prefers-reduced-motion 降级
- [x] 字体 Baloo 2 + 雅黑回退；行高 1.7+
- [x] emoji 仅作关卡图标，不做装饰
- [x] 移动端 ≤640px 单列；min-height 100dvh

## 五、质量红线对照

- 动效可解释：反馈/引导/庆祝三种理由
- 音效温柔：三角波 + 缓起缓落
- 无"答错"：只有"再听一次" + 逼近引导（高一点/低一点）
- 3 错进示范模式，永远有路可走
- 每次改动验证动画不失效（脚本健壮性）
