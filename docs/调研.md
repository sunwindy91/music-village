# 竞品与教学法调研 · 大山里的音乐课

> 用途：初赛答辩差异化论证 + 决赛迭代灵感  
> 对标：Chrome Music Lab / Yousician / 国内儿童音乐启蒙 App（以「小企鹅爱音乐」类产品为代表作机制对比）  
> 教学法：柯达伊 / 奥尔夫 / 达尔克罗兹 → 对照本仓库已落地关卡（`levels.js` + 验收交接包）

## 一、对标产品（各 3 条可借鉴点）

### 1. Chrome Music Lab（Google）

| # | 可借鉴点 | 对本项目的含义 |
|---|----------|----------------|
| 1 | **Song Maker 网格：行=音高、列=时间**，零乐理门槛即可作曲 | 已落地为「旋律田」5×8（`gridPitches` + `compose`）；答辩应强调「同源交互 + 我们多了山谷叙事与五线谱出口」 |
| 2 | **视觉即声音**：点亮色块立刻发声，反馈闭环极短 | 作曲格 `pointerdown` 即 `playMidi`——保持；听辨关避免「听完才能点」过长等待（可加进度点） |
| 3 | **实验集合模块化**（Rhythm、Kandinsky、Spectrogram…）而非单关卡 RPG | 我们用地图串关更适合「课」；可借鉴其「一个机制一个沙盒」——决赛把时值/和弦做成独立可玩沙盒页 |

**差异化（我们已有）**：VexFlow 真五线谱 + MIDI 导出 + 晓声陪伴 + 无账号本地进度（Music Lab 偏实验、无儿童陪伴成长线）。

### 2. Yousician

| # | 可借鉴点 | 对本项目的含义 |
|---|----------|----------------|
| 1 | **实时反馈的「准/不准」可视化**（进度条/色条） | 听唱决赛可借鉴；初赛听辨可用更粗的「再近一点」话术（已有 stumble），少上惩罚条 |
| 2 | **课程树 + 每日小目标**，习惯养成强 | 已有 L0→L1→L2 地点；可加「今天点亮 1 盏灯」地图微目标（勿做成打卡焦虑） |
| 3 | **乐器真实演奏驱动**（吉他/钢琴等） | 山区设备不一，不宜绑定实体乐器；保持「点/拍/听」低门槛，决赛麦克风跟唱作为可选支线 |

**差异化**：Yousician 偏工具课与订阅；我们偏 **零基础叙事世界 + 隐私默认**，更贴乡村教育赛道。

### 3. 国内儿童音乐启蒙 App（类型代表：儿歌/认音符/跟弹类，如「小企鹅爱音乐」等）

| # | 可借鉴点 | 对本项目的含义 |
|---|----------|----------------|
| 1 | **超大触控 + 短回合**（30–90 秒一关） | 我们单关已偏短；注意 intro 打字机不要拖过长（可点气泡跳过——已有 finish） |
| 2 | **强奖励动画与收集物**（贴纸/徽章） | 已有积分 + 音乐会墙 + 晓声成长；可把「点亮地点」做成更明确的收集反馈（金色记号文案已有） |
| 3 | **家长可见的「学会了什么」小结** | 五线谱 PNG「带给爸爸妈妈看」已是钩子（`staffReady`）；可在庆祝页加一句孩子话总结：「今天耳朵学会了分高低」 |

**差异化**：多数启蒙 App 内容包在封闭运营内、常需账号；我们 **真乐理内核 + 可导出成品 + 开源式纯前端** 更可复现到乡村机房。

## 二、三大教学法 × 本游戏落地点验证

> 蓝本：`0到1完整设计方案.md` 第二节；实现：`验收交接包_20260812.md` + `src/shared/levels.js`

| 教学法 | 核心主张 | 方案中的玩法设计 | 当前仓库验证（已实现 / 部分 / 未做） | 证据 |
|--------|----------|------------------|--------------------------------------|------|
| **柯达伊** | 先唱后学；首调唱名；手势/节奏音节 | 「唱」关、唱名、手号 | **部分** | ✅ `notes` 认识音符：唱名 do–si + 简谱 1–7，渐进解锁（验收包 P1）；❌ 麦克风回唱判准、手势 UI **初赛未作为可玩主路径**（方案有、交付以听选为主） |
| **奥尔夫** | 打击乐、身体律动、即兴 | 「拍」关、自由敲击 | **已落地主路径** | ✅ `drum` 小鼓手：走—走—走—停，拍垫 + 节奏窗口判拍（`drumWindowMs`/`drumHitRate`）；⭕ 自由即兴敲击成段 — 旋律田可视为「音高即兴」，纯节奏即兴仍可加强 |
| **达尔克罗兹** | 体态律动、听辨反应 | 「听」关：听→点/做动作 | **已落地主路径** | ✅ `highlow` 谁更高、`same` 听音找家：真实 MIDI 听辨 + 点选反应；体态（全身动作）受网页限制，用「点/拍」代替身体位移——答辩需诚实说明 |

### 落点一句话（可直接用于答辩）

> 奥尔夫的「拍」和达尔克罗兹的「听—反应」已经变成孩子手指上的关卡；柯达伊的唱名认知已进「摘果子」，「唱出来再机器判」留给决赛——我们宁可先把听对、拍对、写出真谱子做透。

## 三、对决赛的 5 条调研结论（非本轮开发）

1. 保持 Music Lab 级「一秒出声」，不要加长教程墙。  
2. 奖励用「成长与作品」代替排行榜，贴合乡村与儿童心理。  
3. 柯达伊补齐：可选麦克风关 + 手势动图，失败不挡主线。  
4. 家长小结一屏：今日概念（高低/同异/唱名/节奏）+ 一张谱。  
5. 竞品别追 Yousician 的乐器深度，追「无师也能走完 L0–L2」。
