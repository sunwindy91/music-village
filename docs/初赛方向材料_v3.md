## 一、项目一句话

**给山区音乐零基础的孩子，一个 AI 陪伴的「乐理寻宝」游戏**——把抽象的音高、节奏、创作，变成大山世界里看得见、摸得着、玩得懂的规则。孩子玩着，就把真乐理学会了。

## 三、核心产品设计（P0+P1 全量完成版）

### 世界观（小鹿乱撞）
> 大山被「静默」封印了。晓声——住在晨雾山谷里的小山灵——**忘记了自己会唱歌**，请孩子陪她一起把声音找回来。每点亮一座山，山谷就重新唱响一分；晓声也在孩子的陪伴中一步步长大，直到蜕变成一头小鹿。

### 山路寻宝地图（5 聚类已全部上线）
5 个聚类串成主线：**声音山谷（L0 听觉启蒙）→ 音阶山谷（L1 乐理主课：认谱/时值/音程，对齐叔叔大纲）→ 节奏小路（节奏进阶：十六分）→ 和弦花园（和声启蒙）→ 旋律草原（L2 创造表达）**，每个聚类 = 理论导入 → 关卡练习 → 乐理小测三段闭环，通关点亮、循序渐进。

### 已实现关卡（5 聚类 · 21 关 · 全部真实乐理判题）

> 下表为 P0 首批 5 关样例；全量 21 关（16 玩法 + 5 乐理小测）清单见 `src/shared/levels.js` 与 `docs/聚类课程架构_v1.md`，冒烟 52 项断言全 PASS。

| 地图 | 关卡 | 乐理点 | 演示点 |
|------|------|--------|--------|
| 声音山谷 | 谁更高 | 音高听辨 | 两个真实音符比高低，tonal MIDI 判题零误差 |
| 声音山谷 | 小鼓手 | 节奏感知 | 拍点窗口 ±400ms（儿童容差），60% 命中过关；失败自动降速（bpm 88→76→72）再拍 |
| 声音山谷 | 听音找家 | 音高辨识 | 即时反馈 + 逼近式引导 |
| 音阶山谷 | 认识音符 | 唱名+简谱 | do-re-mi → 全 1-7 渐进解锁；**答错报正确答案 + 再播该音**（认全机制） |
| 旋律草原 | 旋律田 | 网格作曲 5×8 | 一键 **VexFlow 真实五线谱** + PNG/MIDI 导出 + 音乐人格卡 |

### 核心机制：乐理三件套（可复制到所有地图）
每个关卡 = ①乐理概念 ②心智模型 ③游戏动作 + 判定规则 + 反馈协议 + 目标。不懂乐理的队友照模板填配置即可新增关卡（`src/shared/levels.js`）。

### 晓声 · AI 山灵（陪伴核心）
- **角色**：3D 立体手办山灵（21 张多姿态素材），打字机气泡 + 情绪姿态换图（答对开心/答错安抚/卡关好奇/通关庆祝）+ 萤火粒子
- **真实语音**：edge-tts 离线语音包（16 条：欢迎/下一站引导/鼓励语），晓声会「开口说话」并主动引导孩子去下一关
- **6 阶段成长形态**：种子→小芽→开花→星光→初鹿→鹿，由主线聚类进度驱动；形态切换带**蜕变动画**（金色粒子爆发）
- **课堂陪伴 · 卡关不判死**：连续错 2 次，晓声主动安抚 + 降难度重播（stumble 话术）；没有「答错」，只有「再听一次」
- **认全机制**：认识音符答错即报正确答案并重播该音，学习闭环
- **成长仪式**：首次通关「你点亮了这座山…」、再次通关「金光飞过来了…」
- **主题曲框架**：5 关全部点亮后自动奏响主题曲（`config.themeSong`），歌名上屏；旋律/歌词由老师与孩子共同谱写
- **积分闭环**：答对 +10 / 通关 +50 / 作曲 +30，顶栏积分 + 飘字动画 + localStorage 持久化 + 「我的音乐会」作品墙
- 决赛接入大模型对话（架构已预留，初赛本地规则引导保证弱网可用）

## 五、技术方案

- **真实乐理引擎三件套**：tonal（MIDI 判题零误差）+ Tone.js（温柔音色/节奏调度）+ VexFlow（真实五线谱渲染），全部浏览器端运行
- 纯前端 Vanilla JS + SVG，零构建链、零依赖安装，低配友好
- **全部本地化**：Tone/tonal/VexFlow 三个库本地 vendor，素材全量 webp（18MB→1.2MB），**离线可用**
- 数据：localStorage 本地存储（无账号、零个人信息、儿童隐私合规）
- AI：初赛本地规则引导（稳定）；决赛接入大模型（config 开关预留）
- 部署：Cloudflare Pages（国内可访问）
- 质量：`node tools/smoke.js` **27 项断言全 PASS**（含真实五线谱 SVG、会话令牌、事件兼容层）
- 演示视频：3 分钟演示脚本（`docs/演示视频脚本_3分钟.md`）
