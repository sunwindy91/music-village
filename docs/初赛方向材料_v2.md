## 一、项目一句话

**给山区音乐零基础的孩子，一个 AI 陪伴的「乐理寻宝」游戏**——把抽象的音高、节奏、和弦，变成大山世界里看得见、摸得着、玩得懂的规则。

## 二、解决的真实问题

| 痛点 | 我们的方案 |
|------|-----------|

| 孩子对乐理零基础、怕枯燥 | 游戏化寻宝：乐理=世界规则，玩中学 |

## 三、核心产品设计（v0.2 已可玩）

### 世界观
> 大山被"静默"封印了。和山灵一起，从山脚走向山顶，收集音符、点亮石碑，让大山重新唱歌。

### 山路寻宝地图
5 个地点串成一条路：声音山谷(L0) → 音阶山谷 → 节奏小路 → 和弦花园 → 旋律草原。每个地点 = 一个乐理模块。

### 已实现关卡（音阶山谷 · 三关闭环）
| 关卡 | 类型 | 乐理点 | 演示点 |
|------|------|--------|--------|
| 看小鸟飞 | 观察（零压力）| 音高=位置 | 五线谱+彩色轨迹 |
| 点小鸟回家 | 配对（有判定）| 音高辨识 | 即时反馈+逼近引导 |
| 排排队 | 排序（心智模型）| 音阶=从低到高 | 排队+音阶响起 |

### 核心机制：乐理三件套（可复制到所有地图）
每个关卡 = ①乐理概念 ②心智模型 ③游戏动作 + 判定规则 + 反馈协议 + 目标。**不懂乐理的队友照模板填配置即可新增关卡**（`src/shared/levels.js`）。

### AI 山灵
SVG 森林精灵角色：打字机对话、表情切换（开心/思考/庆祝）、答错时"高一点/低一点"逼近式提示、3 错进入示范模式。决赛接入大模型对话（接口已预留）。

## 五、技术方案

- 前端：Vanilla JS + Web Audio API + SVG（零构建链，低配友好）
- 数据：localStorage 本地存储（无账号、零个人信息、儿童隐私合规）
- AI：初赛本地规则引导（稳定）；决赛接入大模型（config 开关预留）
- 部署：Cloudflare Pages（国内可访问）
- 演示视频：3 分钟（脚本见 `docs/演示视频脚本_3分钟.md`）
