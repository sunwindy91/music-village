## 2. 晓声 TTS 真实语音（免费音源适配）

### 免费方案对比
| 方案 | 成本 | 中文音质 | 集成方式 | 结论 |
|---|---|---|---|---|
| **Edge TTS**（微软） | 免费 | 佳（XiaoxiaoNeural 温柔女声） | 本机 Python `edge-tts` 预生成台词 mp3 → 前端 `<audio>` | ✅ 首选：离线、零收集、纯前端 |
| Web Speech API（浏览器内置） | 免费 | 一般（依赖系统语音） | `speechSynthesis.speak()` | 备选：零配置但音质不稳 |
| ChatTTS / GPT-SoVITS | 免费开源 | 佳（可克隆晓声音色） | 本地推理（需 GPU/算力） | 进阶：音色定制，工作量中 |
| Fish Audio / 讯飞 / Azure | 免费额度有限 | 佳 | API（需 key/服务端） | 不优先（红线：零收集/无服务端） |

### 推荐执行（Edge TTS 语音包）
1. 本机 `pip install edge-tts`（Python 3.13 已有环境）
2. 用晓声台词语料生成核心语音包（~20 句，见 `tools/gen_tts.py`）：
   - 欢迎 3 句、卡关陪伴 4 句、通关 4 句、下一站引导 5 句、鼓励语 4 句
   - 音色：`zh-CN-XiaoxiaoNeural`（温柔）或 `zh-CN-XiaoyiNeural`（少女）
   - 输出：`src/assets/voices/*.mp3`（小体积，语音平均 3-5s ≈ 60-100KB）
3. 前端：`VoiceCore.sayVoice(key)` —— 播音频 + 同屏气泡文字 + 姿态（失败回退文字气泡）
4. `VoiceCore` 增加语音层，与姿态层/气泡层并存

## 4. 哼唱生成歌曲（纯前端 · 零收集）

### 方案（无需外部 API，符合红线）
1. **录音**：`MediaRecorder` 录小朋友哼唱（或老师示范）
2. **音高提取**：复用项目已有乐感检测（`#/pitch`），采样 → 音高序列 → 量化到 12 音阶
3. **转旋律**：音高序列 → `{midi, start, dur}` 音符数组 → 进「旋律草原 / 我的音乐会」
4. **AI 配伴奏**：Tone.js 依据旋律自动配和弦（如根音五度循环/简单三和弦进行）
5. **成歌**：旋律 + 伴奏 + 晓声鼓励 → 保存为作品

### 备注
- 若要「专业人声歌曲」：由老师/家长用 **Suno**（见 §7）哼唱参考生成，成品作主题曲/示范
- 产品内哼唱生歌保持纯前端（可离线演示）

## 6. 高度智能嵌入的交互想象（蓝图）

若嵌入更强模型（本地小模型 / 服务端），晓声可以：
- **对话式教学**：小朋友问「do 在哪里」，晓声演示并考一考
- **自适应难度**：连续答错自动降难、答对加速推进（stumble 已有人工版，AI 版更细）
- **情感陪伴**：识别挫败语气，切换安抚姿态+专属台词
- **个性化命名**：记住孩子的名字/喜好（本地存储，零收集）
- **哼唱识别**：实时跟唱纠音（音高曲线对比）
- **生成式作曲**：孩子哼一句，AI 续写完整旋律

优先级：TTS 语音包 → 哼唱生歌 → 自适应难度（AI 版）→ 对话式教学
