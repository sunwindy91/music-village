# 🎨 晓声 · 生图 Prompt 清单

> 用途：用 AI 生图工具（即梦 / 可灵 / Midjourney）生成晓声形象与 5 张地图背景
> 风格统一：**水彩 + 光粒子 + 空灵治愈**（参考《灵魂摆渡人 Spiritfarer》）
> 生成的图 → 放 `music-village/src/assets/` → 前端作为背景/角色使用

## 一、晓声（主角形象）

### 1. 晓声 · 初始（透明小鹿，未找回记忆）
```
水彩风格插画，一只透明半透明的幼鹿，像清晨雾气凝成的小鹿，几乎融入山色，
身体由浅淡的蓝白色光点构成，眼睛温柔好奇，安静地站在晨雾山谷里，
周围漂浮着细微的萤火光点，空灵治愈，柔和光线，浅蓝米白暖金色调，
干净背景留白，儿童绘本质感
```

### 2. 晓声 · 中段（找回部分记忆，有了色彩）
```
水彩风格插画，一只小鹿，身体从透明开始有了温暖的浅金色和浅绿色渐变，
身上浮现有细小的音符花纹和花瓣光点，眼神活泼了一点，站在开满小花的山谷中，
阳光从云缝洒下，萤火光点环绕，空灵治愈，柔和水彩，浅色调，儿童绘本质感
```

### 3. 晓声 · 完全苏醒（长出光之翅膀，即将飞翔）
```
水彩风格插画，一只小鹿全身被流动的彩色流光包裹，背后展开一对由金色和
彩虹光点构成的巨大光翼，身体上有音符和花朵的纹理，眼睛明亮闪着光，
正轻轻跃向天空，周围光点如星尘飘散，山间晨光从背后照亮，空灵神圣，
柔和水彩，金色暖光，儿童绘本质感
```

## 二、5 张地图背景（每个一张，远景/氛围图）

### 1. 声音山谷（她的摇篮 · 晨雾）
```
水彩风景，清晨的宁静山谷，轻雾缭绕，溪流在谷底闪光，远处群山柔和，
几只小鸟停在树梢，露珠和光点，空气感强，浅蓝米白暖金色调，
柔和光线，儿童绘本质感，大量留白
```

### 2. 音阶山谷（她的歌喉 · 星空歌台）
```
水彩风景，山谷中有一片露天歌台，五线谱像光带飘在夜空，星星如音符散落，
一棵会发光的大树下有篝火般温暖的微光，蓝紫色夜空配暖金色灯火，
空灵治愈，儿童绘本质感
```

### 3. 节奏小路（她的脚步 · 萤火小路）
```
水彩风景，一条蜿蜒的乡间小路穿过森林，路边开满萤火虫光点，像音符一样
一闪一闪，风吹动野花和草，有小动物脚印形状的光斑，深绿色调配暖黄光点，
空灵治愈，儿童绘本质感
```

### 4. 和弦花园（她的花园 · 彩色花园）
```
水彩风景，一座被晨光洒满的花园，三色花朵（红/黄/蓝）环绕着一座发光的
石碑，花园里悬浮着彩色的光团（像和弦），蝴蝶和光尘，粉绿金暖色调，
空灵治愈，儿童绘本质感
```

### 5. 旋律草原（她的梦 · 流光大草原）
```
水彩风景，开阔的草原延伸到天际，一道由彩色光点组成的旋律丝带在草原上
蜿蜒飘动，像流动的银河，远方是山与晨光，风在草尖流过，蓝紫金色调，
空灵治愈，儿童绘本质感
```

## 三、操作步骤

1. 打开 **即梦**（jimeng.jianying.com）或 **可灵**（klingai.com）
2. 粘贴上述 prompt，生成（4:3 或 16:9 横版，1 张/场景）
3. 不满意就加"更空灵 / 更简洁 / 更柔和"
4. 导出 PNG → 放入 `music-village/src/assets/`
5. 告诉我文件名，我来接入前端（背景层 + 晓声形象替换）

## 四、接入计划（拿到图之后）

| 图 | 用在哪 |
