## 一、五层问题模型（你的反馈 → 系统定位）

| 层级 | 你的感受 | 具体问题 | 方案 |
|------|---------|---------|------|
| **L1 交互层** | "鼠标乱晃""死板" | hover 摇晃动画；缺"返回/下关"导航 | 去晃动物画只留发光 ✅ / 补返回按钮 ✅ / 完善前进-后退 |
| **L2 表现层** | "静态渲染""没美感" | 地图/舞台静态；不灵动 | SVG 动态化：溪水流动/云飘/星光/音符脉动 |
| **L3 内容层** | "只能作为一个部分" | 只有音高/音阶，节奏/和弦/旋律没实现 | 用关卡模板扩展：节奏小路(tap)/和弦花园(collect)/旋律草原(draw) |
| **L4 灵魂层** | "没有灵魂""割裂" | 关卡各自独立，缺主题和叙事 | **「晓声」灵魂线**（见下）：5 张地图 = 帮晓声找回记忆的旅程 |
| **L5 智能层** | "山灵哪有 API""能像豆包聊天吗" | API 只是预留；无语音对话 | 接**通义千问**（比赛要求）+ 语音（听+说）+ 前端 proxy |

## 二、灵魂线设计（系统论核心：让部分不割裂）

> **世界观升级**：大山里住着一个歌声精灵 **晓声**。她因为"静默"封印，忘了自己会唱歌。
> 孩子（玩家）每点亮一张地图，就帮晓声**找回一段记忆**，直到她完整苏醒、重新歌唱。

| 地图 | 晓声的记忆 | 主题表达 | 实现关卡 |
|------|-----------|---------|---------|
| 🏞️ 声音山谷 | 她的摇篮 | 从倾听世界开始 | 谁更高 / 小鼓手 / 听音找朋友 ✅ |
| ⛰️ 音阶山谷 | 她的歌喉 | 找回高低上下 | 看小鸟飞 / 点小鸟回家 / 排排队 ✅ |
| 🛤️ 节奏小路 | 她的脚步 | 找回走走停停 | 小鼓手(tap) → 节奏闯关 |
| 🌸 和弦花园 | 她的花园 | 三色花=和声 | 收集三色音符 → 点亮彩虹石碑 |
| 🌾 旋律草原 | 她的梦 | 画出自己的歌 | 指挥小鸟画旋律线 → 自由创作 |

**终点仪式**：5 张地图全亮 → 晓声完整苏醒 → 和孩子一起唱一首歌（通关全旋律）。

> 这样每个关卡不只是"练乐理"，而是"帮晓声找回一段回忆"——有主题、有情感、有终点。

## 三、逐层方案

### L1 交互层（手感）
- ✅ hover：去掉旋转摇晃，只保留双层光晕（发光=可点直觉）
- ✅ 关卡视图顶部加"← 返回地图"
- 已有：通关后"下一关/全通关回地图" + 关卡 chips 切换
- 待做：观察模式播放中可随时暂停返回；音效 hover 提示（极轻）

### L2 表现层（动态渲染）
用 CSS animation + SVG SMIL（轻量、低配友好）：
- 地图：溪水 `stroke-dashoffset` 流动、云左右飘、星光闪烁、晓声小鸟偶尔飞过
- 舞台：音符落点 `pulse` 发光、通关时彩色光点飘散（已有 pop-note 可加强）
- 山灵：晓声身边常有萤火虫光点环绕（sparkle 已有）

### L3 内容层（扩展地图，复用模板）
| 地图 | 关卡类型（复用） | 内容 |
|------|----------------|------|
| 节奏小路 | tap（跟拍）+ sort | 时值=距离：音符滚动判定、走走停停 |
| 和弦花园 | collect（新：收集三色）| 三和弦=颜色合成：收集 do-mi-sol → 彩虹石碑 |
| 旋律草原 | draw（新：轨迹创作）| 指挥小鸟飞 → 画出旋律线 → 播放 |

> 模板已支持（levels.js 配置 + 关卡类型），队友/后续照填即可。

### L4 灵魂层（晓声）
- **命名**：晓声（"晓"=知晓/天明，"声"=歌声）→ 采纳 ✅
- **形象**：先做"回声小精灵"（SVG 已有基础：光点+翅膀+温暖脸），后续队友细化皮肤
- **叙事**：开场故事 + 每张地图解锁时的晓声回忆动画 + 终章苏醒

### L5 智能层（千问 API + 语音）
- **比赛要求**：用通义千问（纯语言模型，正好我们是文本交互+音频，非多模态）
- **架构**：前端 UI → Cloudflare Worker(proxy，藏 key) → DashScope(千问) → 回传文案 → `speechSynthesis` 朗读（像豆包说话）
- **听**：`SpeechRecognition`（孩子说话 → 文本 → 千问）
- **山灵接入点**：`VoiceCore.askSpirit()`（已预留）+ `config.js` 开关
- **初赛**：演示"晓声能聊"（1-2 个自由对话）+ 本地规则兜底
- **注意**：初赛纯前端无后端 → proxy 用 Cloudflare Worker（免费）
