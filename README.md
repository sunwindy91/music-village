## 项目定位

先让孩子**爱听爱唱** → 再**看懂乐谱** → 最后**玩出旋律**。

核心不是"教乐理"，是让孩子愿意打开、愿意坚持、感受到音乐的美好。

## 三层结构（教育心理学指导）

- **L0 听觉启蒙**（初赛核心）：听音找朋友 · 节奏拍打 · 高低音对比
- **L1 乐理进阶**（叔叔专业大纲）：音符 → 时值 → 旋律 → 音程 → 和弦
- **L2 创造表达**（愿景激励）：音乐人格 · 哼唱生成

## 双 Agent 协作（A2A）

```
├─ main          ← 稳定版主分支
├─ module-audio  ← 听觉/乐理/引导/积分（邹翔）
├─ module-voice  ← 语音/旋律/视觉/动画（队友）
```

**接口契约先行**：`MusicCore` / `VoiceCore` 先定接口，各自实现，PR 合并。
